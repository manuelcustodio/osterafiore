# Osteria Fiore

## Nombre

Osteria Fiore

## Descripción

MVP universitario de la página web de un restaurante italiano ficticio ubicado en el Distrito Nacional, Santo Domingo. En esta primera etapa el visitante puede conocer el negocio, consultar el menú, filtrar platos y comenzar un pedido desde el carrito.

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla

## Ejecución

Abrir el archivo `index.html` en un navegador. No es necesario instalar nada ni usar un servidor.

## Funcionalidades

- Página principal con encabezado, navegación, hero y sección sobre nosotros
- Menú con categorías: Entradas, Pastas, Pizzas, Postres y Bebidas
- Filtro de productos sin recargar la página
- Platos destacados
- Agregar productos al carrito
- Cálculo básico del total
- Diseño inicial y versión responsive básica
- Información de contacto visible

## Cambios
